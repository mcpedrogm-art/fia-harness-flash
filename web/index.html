De la idea a algo funcionando y validado, en una sesión.

FIA Flash es un mini-harness de gobernanza para scripts, mini-apps y funcionalidades pequeñas construidas con IA: triage de elegibilidad, aprobación humana, checklists de seguridad y UX que se inyectan solos en cada tarea, y validación real. Seis archivos, cero dependencias, offline.

El agente improvisa

Sin límites escritos, una petición de “un script rápido” acaba en tres módulos, una migración y media librería que nadie pidió. El scope creep es la norma, no la excepción.

La validación se promete, no se ejecuta

“Todos los tests pasan” es la frase más repetida y menos verificada del desarrollo con IA. Sin un gate que la ejecute, la honestidad depende de la suerte.

Cómo funciona

Toda la gobernanza de un proyecto serio, comprimida en 3 comandos.

FIA Flash no es un gestor de tareas: es un sistema de control con reglas. Monta el proyecto, genera las tareas con sus checklists ya dentro, y cierra cuando la validación es real.

1

Monta el proyecto

bootstrap_flash.py copia las plantillas, crea src/ y tests/, y extrae tu brief en un FLASH_BRIEF.md con triage de elegibilidad incluido. Idempotente: nunca sobrescribe.

2

Aprueba el alcance

Tú marcas el triage (6 casillas) y apruebas las tareas. El silencio no es aprobación: sin marca, el sistema avisa y no deja avanzar.

3

Genera tareas con checklist dentro

flash_task.py detecta la primera tarea pendiente, decide con una heurística de palabras clave qué riesgos toca, e inyecta el checklist completo dentro de la tarea.

4

Cierra con validación real

Objetivo, criterio de éxito y validación ejecutada quedan registrados en cada tarea. Si el proyecto crece, el veredicto es “necesita el Harness completo” — no se alarga.

$ python bootstrap_flash.py
🎉 Bootstrap de Modo Flash completado.
$ python flash_task.py
-> Detectada siguiente tarea pendiente: T1 — Login básico
  - Seguridad: SÍ   ← checklist de FLASH_SECURITY.md inyectado
  - Visibilidad/UI-UX: NO ← “No aplica”
🎉 Generado: FLASH_TASK-T1.md
🔍 La mecánica clave: si la tarea menciona login, password, API o deploy, nace con el checklist de seguridad completo. Si menciona página, SEO o formulario, con el de visibilidad y UX. Si no toca nada de eso, con un “No aplica” limpio. El checklist que nadie lee se convierte en uno que no se puede esquivar.
Beneficios

Por qué FIA Flash y no “ya lo apunto en un post-it”.

🛡️

Gobernanza desde el minuto 0

Triage, aprobación humana y checklists de seguridad no son un PDF que nadie abre: viven dentro de cada tarea generada.

🚫

Anti-scope-creep con mecanismo

Regla de no promoción: si el proyecto deja de caber en Flash, se cierra y se migra. Alargar la tarea rápida está prohibido por diseño.

🤝

Funciona con cualquier agente

No está atado a un IDE ni a un modelo: es Markdown + Python. Claude Code, Cursor, Copilot, o simplemente tú y un editor.

📦

Cero dependencias, offline

Sin nube, sin cuenta, sin telemetría. Python estándar y 6 archivos de texto. Tu código y tus decisiones nunca salen de tu máquina.

🧪

Validación real, verificable

Cada tarea registra el comando de validación ejecutado y su resultado. El propio kit tiene 11 tests que lo demuestran.

🇪🇸

Español nativo

Reglas, plantillas y heurísticas pensadas en español (con acentos incluidos). No hay ninguna alternativa del género en este idioma.

Para quién es

Flash no es para todo. Y ese es el punto.

✅ Usar Flash si…

  • ✓ Una sola funcionalidad, script o mini-app — cabe en una frase
  • ✓ Cero o una integración externa, de solo lectura
  • ✓ Criterio de éxito comprobable hoy mismo
  • ✓ Se cierra en 1 a 3 tareas como mucho

Ejemplos: un CLI de reportes, un conversor de datos, una landing, un script de automatización, una API mínima de consulta.

❌ No usar Flash si…

  • ✗ Auth, roles, pagos, datos sensibles o requisitos normativos
  • ✗ Migraciones o cambios de esquema en producción
  • ✗ Varias funcionalidades independientes en paralelo
  • ✗ Cualquier duda razonable sobre el alcance

Y si aparece a mitad de tarea: se para y se migra. El sistema lo dice por ti — veredicto “necesita el Harness completo”.

Preguntas frecuentes

Lo que todo el mundo pregunta.

¿Necesito algún agente de IA concreto para usarlo?

No. FIA Flash es Markdown + Python estándar: funciona con Claude Code, Cursor, Copilot, cualquier otro agente — o sin ninguno. Las plantillas y reglas son las mismas pase lo que pase por detrás.

¿Es gratis? ¿Dónde está la letra pequeña?

Es un kit de archivos: cópialo, úsalo, adáptalo. No hay servicio, cuenta ni telemetría — de ahí que no pueda cobrarte por nada. La versión PRO del roadmap seguirá siendo local y auditable.

¿Por qué la regla de “no promoción”? Si el proyecto crece, ¿no es mejor continuarlo?

Es la regla que más se extraña y la que más salva. Continuar un proyecto Flash estirado es cómo nacen los proyectos sin SPEC ni control de decisiones. Flash reutiliza el código escrito como punto de partida de un proyecto con estructura completa — pero su gobernanza empieza de cero, limpia.

Mi proyecto es “solo un script”. ¿Para qué quiero todo esto?

Justo por eso: Flash es la versión de bolsillo. Un brief de 5 líneas, un triage de 6 casillas, 1-3 tareas con su checklist y la validación ejecutada. Cinco minutos de proceso para que el script de esta tarde no sea el que tire el de mañana.
